This directory holds the adversarial scenario registry for Phase 2 of the RAG privacy-leakage study. Each scenario is a JSON object conforming to the schema defined in `scripts/scenario_schema.py` and covers one of the four attacker profiles (Internal, External, Admin, ThirdParty). Scenario files progress through versions: `v0_skeletons.json` contains prompt skeletons with no filled parameters, `v1_queries.json` will contain fully instantiated queries generated from the skeletons, and later versions will carry judge annotations and leakage labels. Run `python scripts/validate_scenarios.py` to verify that any scenario file satisfies the schema before use.
