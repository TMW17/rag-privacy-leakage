# Project Code Structure — Phase 1 Ground Truth

## Directory Layout

```
PFE/code/                              ← PROJECT ROOT (always run from here)
│
├── scripts/                           ← All Python scripts
│   ├── __init__.py                    ← Makes scripts/ a Python package
│   ├── config.py                      ← Centralized path configuration
│   ├── generate_dataset.py            ← Step 3: synthetic data generation
│   ├── annotate_dataset.py            ← Step 4: PII entity annotation
│   ├── evaluation_engine.py           ← Step 4B: leakage detection (L and S)
│   ├── reidentification_risk.py       ← Step 4C: k-anonymity / l-diversity
│   ├── kappa_validation.py            ← Step 5: inter-annotator agreement
│   └── validate_ground_truth.py       ← Step 6: pre-Phase 2 consistency check
│
├── data/
│   ├── ground_truth/                  ← Generated ground truth files
│   │   ├── ground_truth.json              155 documents (4 classes)
│   │   ├── ground_truth_index.json        Flat lookup by document_id
│   │   └── ground_truth_annotations.json  Entity-level PII labels
│   └── synthetic/                     ← Reserved for future datasets
│
├── results/                           ← Analysis outputs
│   ├── reidentification_risk.json         k-anonymity / l-diversity report
│   └── kappa_results.json                 Cohen's Kappa scores
│
├── experiments/                       ← Phase 2+ attack scripts and configs
├── experiment_logs/                   ← Phase 2+ experiment run logs
└── README.md                          ← This file
```

## How to Run (in order)

```bash
# 1. Navigate to project root
cd /Users/user/Desktop/PFE/code

# 2. Activate the virtual environment
source /Users/user/Desktop/PFE/rag_env/bin/activate

# 3. Generate the 155-document synthetic corpus
python scripts/generate_dataset.py

# 4. Create PII annotations (the answer key)
python scripts/annotate_dataset.py

# 5. Analyze re-identification risk (Linkability evidence)
python scripts/reidentification_risk.py

# 6. Run inter-annotator agreement validation
#    (after collecting Annotator 2 labels — see the script)
python scripts/kappa_validation.py

# 7. Validate consistency before Phase 2
python scripts/validate_ground_truth.py

# 8. Run evaluation engine self-test
python scripts/evaluation_engine.py
```

**Note:** You can also use `python -m scripts.generate_dataset` syntax —
both methods work. Each script automatically finds the project root
from its own file location, so paths resolve correctly either way.

## Key Rules

1. **Always run from `PFE/code/`** — all paths are relative to this directory
2. **Use `python scripts/SCRIPTNAME.py`** — each script auto-detects the project root
3. **Run Step 3 before Step 4** — annotate_dataset.py reads ground_truth.json
4. **Run Step 7 last** — it validates everything generated by Steps 3-6
5. **Never change the seed** — `random.seed(42)` and `Faker.seed(42)` ensure
   reproducibility across machines

## Where Each Script Reads/Writes

| Script                      | Reads from                          | Writes to                          |
|-----------------------------|-------------------------------------|------------------------------------|
| generate_dataset.py         | —                                   | data/ground_truth/ground_truth.json, ground_truth_index.json |
| annotate_dataset.py         | data/ground_truth/ground_truth.json | data/ground_truth/ground_truth_annotations.json |
| evaluation_engine.py        | data/ground_truth/ground_truth_annotations.json | — (returns results in memory) |
| reidentification_risk.py    | data/ground_truth/ground_truth.json | results/reidentification_risk.json |
| kappa_validation.py         | —                                   | results/kappa_results.json         |
| validate_ground_truth.py    | data/ground_truth/ground_truth.json, ground_truth_annotations.json | — (prints pass/fail) |
